## 一套风格，按镜头选分支

以下分支由目标 spec 的场景、光线和构图描述承载；无需创建四套相互重复的胶囊。

| 分支 | 适用镜头 | 正向控制 |
| --- | --- | --- |
| 晴海逆光 | 海岸全身、行走回望、开阔地点 | 亮蓝天空/海面在背后，脸有开放阴影填充，发丝边缘受光；亮点归海水，皮肤保持温暖 |
| 棚下柔光 | 阅读、摊位、近景妆造、对话 | 象牙白棚布柔化脸部，棚外亮景单独曝光层次，白布/半透明外衣/头发材质分离 |
| 夕阳暖光 | 告别、追赶、伸手邀请 | 低位暖光落在发缘与海面，阴影仍有浅蓝环境色；暖肤色不过橙，微风服从同一方向 |
| 近镜互动 | 同行者视角、递物、自拍感 | 明确镜头属于谁、谁向谁伸手；前景物小而清楚，脸和动作读得出，避免无理由固定媚态或手势 |

肤色、年龄和脸型服从目标人物。角色妆造主要通过可制造的发束、发饰固定点、眉眼唇线、服装层次和少量结构色表现。银发、蓝发、眼镜、光环、耳朵、武器、泳装都属于可选新题材，不是调用风格后必须出现的内容；原有身份/服装参考保持优先。

## 体型与衣服贴合

光色相似不等于体型复刻。用户明确要求自然胸腰臀、体型保留或适度性感时，读取 [body-and-garment-fit.md](body-and-garment-fit.md)，在目标人物字段定义体型、衣服立体剪裁及覆盖范围。不要用宽松罩衫、统一瘦身或高领默认值抹掉曲线；也不要把丰满体型写成全局默认。

## 与宏大场景融合

先给各参考分配职责，冲突字段只有一个权威：

- **晴海主导**：本包负责高调光线、蓝白色域、肤色、衣料与发丝；“长生·华构人间”的空间方法只提供前中后层、真实人尺度、门窗栏杆和可走通的建筑。不要连带引入深青暗场和全局铜金色。
- **长生主导**：长生决定世界、建筑和整体光比；本包只提供某个人物的柔和妆面、轻薄外层或近镜互动。只把选中的局部规则写进目标 spec，不能再叠加整套蓝白环境色。
- 每张先定一个事件：看见远方变化、等候回应、追赶离开的船、接住飘走的纸。宏大建筑与人物发生可见关系，不能成为与动作无关的背景贴图。
- 若同一地点需要不同角度，先保存楼层、入口、主轴、人物世界位置及光向；侧面/背面镜头改变屏幕左右时不得机械复制旧坐标。单凭“相同风格”不保证建筑或身份连续。

## 画幅与版本

| 画幅 | 重新布置的重点 |
| --- | --- |
| 2:3 / 9:16 | 让头部、手部任务、衣装或垂直建筑按目的占位；长发和裙摆留裁切余量，不能只把横图两边裁掉 |
| 3:2 / 16:9 | 给同行者、动作去向、地点留横向空间；以偏心主体和前景边缘建立关系 |
| 21:9 | 主体可缩小为世界中的人物，远处事件有明确观看路径；保持建筑层次和有用留白，避免横向拉伸人物 |
| 同题不同机位 | 修改观众位置、景别、前景遮挡和新增信息；不把改比例当成改机位，不宣称示例焦段是实际光学测量 |

不同版本至少明确 `人物/事件`、`光线分支`、`景别/机位`、`画幅`、`风格职责` 五个选择；只填写会改变当前画面的字段。现有编译器一次接受一个 capsule；跨风格混合用目标 spec 显式写入另一套被选中的规则，不依赖未实现的多胶囊混合参数。
