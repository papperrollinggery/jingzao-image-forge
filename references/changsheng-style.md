## 场景生成

先确定场景功能（居住、商业、议事、工坊等），再选规模与光线，不把所有地方做成大会。

- 建筑：木构、石台、栏杆、门洞与廊桥建立可走通的层次。写清入口、活动面、可视关系和人的尺度；制度场景可用席位高差，私人空间可用门窗与帘幕。
- 配色：明亮庭院用象牙白日光、暖木和局部金色；卧房夜景用格窗冷光加小面积暖灯；公共厅堂用深木、青冷退远层和自然肤色。按目标只选当前所需分支。
- 质感：石材承重、木材结构、金属连接件、布幔透光分别有物理职责。装饰集中在视线需要停留的区域，远景降低对比与频率。
- 人的痕迹：等候、阅读、喝茶、工作或交谈中选与任务有关的活动。空场需求保持空场，不自动填满群众。
- 奇观：大尺度地貌或建筑需要人、门、栏杆做尺度锚点。巨树、云海、环形机关、竞技台均属可选题材，不能随风格自动植入。

## 人物、服装、发型、妆面

以下是从观察归纳的设计方法，不是原片角色复刻模板。按目标人物新建 `subjects[].appearance`，保留身份参考。

| 设计轴 | 生成控制 |
| --- | --- |
| 人物辨识 | 先定年龄、面部骨相和处境；保留独立眉眼、轻微不对称及年龄痕迹，不把众人变成同一张年轻美人脸 |
| 服装轮廓 | 明确内领、主衣、外层的穿着顺序和厚薄；大轮廓先于纹样，衣领袖口等局部承接细节 |
| 身份差异 | 日常角色以朴素织物、少量装饰为主；富贵角色可用更繁复领缘、首饰和轻薄外层；权威角色可用更稳定轮廓与厚重材质。它们是按剧情选用的设计建议 |
| 发型 | 发髻/半束发/披发服从角色与动作；写清簪、扣或发带的固定位置，保留成束头发和少量碎发。发饰数量不代替身份设计 |
| 妆面 | 肤色独立于环境青色；按年龄和性格分配眉形、眼周色、唇色；保留皮肤层次与表情活动，不用全脸金属高光或统一磨皮 |
| 饰品和纹样 | 重新设计图案，集中在领缘、袖口、耳边或发结中的少数区域。衣饰接触身体并有重量，首饰不能悬浮 |
| 超自然变体 | 异常眼色、苍白皮肤、黑唇等仅在新角色设定明确需要时添加；不能将局部怪诞镜头当作全片妆容 |

摄影按画面任务选择：环境全景交代空间，关系中景呈现地位或互动，近景呈现皮肤、发型与衣料。脸、手势、服装和背景形成主次；保持眼神和关键衣缘清楚，柔化主要来自景深、亮部过渡和远处空气层。

## 多机位与法术：原创测试扩展

这一节来自新生成样片的可见表现，不是对原片法术、机位或剧情的补充事实。六张有界测试的结果见 [扩展审阅记录](../tests/forward-evidence/changsheng-extensions-review.json)，像素只在本地审阅，不随发行包分发。

- 高斜俯能用中央空区和群众朝向表达秩序被打断；贴地仰视可让门、墙和出口对人物形成压力；窗框遮挡可建立远处观察者的位置。按当前镜头的信息任务选机位，不把每镜改成低角度英雄像。
- 同一法术静帧只冻结一次接触或一次反应。以施法者的手/器物/地面接点为源，写清到目标的路径、接触点、抵抗姿态和局部环境后果。水、火、石、封印有不同材料行为，不用泛光球替代。
- 侧向双人接触适合核对站姿、握持、距离和衣料；过肩近景适合把威胁、保护者和被保护者叠出关系。让效果避开脸与关键衣缘，受力传进腕、肘、脚或地面。
- 多机位必须改变观众位置、遮挡和新增信息。焦段数字只是提示意图，不能仅凭成图认定光学焦段得到精确复刻。
- 本轮较好的例子是高斜俯御庭、水幕接刃、过肩护人。城门空隙、双桥连续几何、石索锁腿没有完全实现；不能把部分通过的接触关系当成已解决。

可复用规格：`tests/forward-specs/changsheng-extension-01-overhead-court.json`、`changsheng-extension-04-side-water-fire.json`、`changsheng-extension-05-shoulder-seal.json`。其余三份同目录规格保留为有局限的测试，不默认采用其失败细节。正常先应用本风格胶囊，再以图像验收判断是否需要针对性修改。
