# 人物风格蒸馏：身材分析卡

人物写真或人物风格蒸馏时，连同光线、构图、妆造一起检查身材信息；使用 [body-profile.json](../templates/body-profile.json) 记录。它是分析侧卡片，不新增 `visual_generation_spec` schema 键。被目标采用的内容仍写入 `subjects[].description`、`subjects[].appearance` 和现有 `constraints`。

非人物蒸馏写 `not_applicable`，不生成这张卡。没有明确的体型迁移要求时，也不把参考人物的体型自动带到新人物；不推广固定女性体型，更不把身材当作可以随风格一并删除的噪声。用户明确要求体型迁移时，保留其已确认的相对比例与服装关系。

## 怎么记录

`observed` 只写图中可见的相对关系：胸—腰—胯轮廓、肩背宽窄与躯干关系、四肢相对长度/体量、可见软组织的自然体量，以及姿态、透视、裁切和遮挡如何影响判断。`garment_coverage_support_fit` 分别记录衣物覆盖、开口、贴合、承托和受力；衣服开口不等于身体曲线。

将设计选择与证据分开：`inferred` 是为新目标提出、但原图不能证明的设计推断；`unknown` 写被遮挡、裁切或无法判断的部分。不要从近景推断隐蔽解剖、罩杯、具体尺寸或年龄。`target_application` 明确哪些要采用、保持或改变；`visual_acceptance` 写成能从成图检查的项目。

## 原创成年人示例

以下是新建目标的分析卡示例，不是对任何参考人物的还原，也不规定其他人物应有相同体型：

```json
{
  "body_profile": {
    "applicability": "person_style_distillation",
    "subject_scope": "原创31岁成年女性，目标时装写真人物。",
    "observed": {
      "chest_waist_hip_relation": ["三分之四身画面中，可见自然胸部体量、轻度腰线收束和连续髋部外轮廓。"],
      "shoulder_back_relation": ["肩宽与髋部平衡；背面未展示。"],
      "limb_relation": ["站姿承重腿略后，前臂被手包局部遮挡。"],
      "soft_tissue_volume": ["躯干体量由合身衣料的顺体阴影可见，不以夸张挤压塑形表现。"],
      "pose_perspective_occlusion": ["正常胸高机位；手包未遮住腰线，画面未提供背面或完整腿部比例。"],
      "garment_coverage_support_fit": ["深蓝连衣裙的合身上身有胸省和腰部接缝；方领开口露出锁骨和少量上胸，主体衣片仍覆盖胸部。"]
    },
    "inferred": ["若改成侧背机位，可为同一原创人物设计相容的背部衣片；这不是从当前正面还原。"],
    "unknown": ["具体身体尺寸、罩杯、背部细节和被裙摆遮住的腿部比例。"],
    "target_application": {
      "adopt": ["自然胸—腰—胯关系、与肩宽协调的躯干比例、衣料承托和顺体垂坠。"],
      "preserve": ["成年身份、当前方领的覆盖边界、自然站姿。"],
      "change": ["把外层改为短夹克时，保持内层合身轮廓；夹克不遮住腰线。"]
    },
    "visual_acceptance": ["胸、腰、髋的相对轮廓在三分之四身构图中可读。", "方领开口与主体衣片覆盖边界同时可见。", "衣料省道、接缝和褶皱与姿势及体量相符。"]
  }
}
```

每次人物蒸馏都检查这张卡是否适用，并只复查本轮新增或变化的身材、姿态和服装证据；无变化的已确认观察可复用。成图验收仍须实际查看人物比例、服装覆盖/承托、姿态和遮挡，不能用卡片存在代替视觉通过。需要将已确认体型与服装要求写入目标提示时，继续阅读 [人物体型、版型与适度性感](body-and-garment-fit.md)。
