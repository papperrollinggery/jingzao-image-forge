# 紫序·产品微观 / Lilac Material Reveal

用于用户明确要求这组产品CG的质感与元素表达、紫白产品TVC、材质微距、细粉释放或有秩序的产品阵列。不是所有产品的默认滤镜。风格包：[lilac-material-reveal.json](style-capsules/lilac-material-reveal.json)。已获用户授权收录；经跨产品视觉复核后状态为 `adopted`，具体残余偏差仍见下方记录。

这里蒸馏的是实际产品分镜与其公开可读的设计理由，不是模型隐藏思维，也不是对源项目客户验收状态的确认。来源任务读取接口当时不可用，因此使用已核对目录中的7张分镜/候选图、研究文稿与实际送模记录；原项目仍在推进，结论只绑定本次看到的版本。客户原图、品牌、私有路径、完整提示词和方案不随包分发。

## 视觉核心

| 维度 | 可迁移的控制 | 不能变成通用默认 |
|---|---|---|
| 空间与色彩 | 上方淡紫、下方冷白的低频棚景，产品本色独立；近大远小与克制投影建立纵深 | 所有产品都染成紫色、每张都悬浮、所有构图都复制源阵列 |
| 硬壳 | 宽柔长条反射、连续细倒角、可读暗部，连接与开合结构保持刚性 | 整体油亮、金属化、软化包装，或复制来源特定盒型 |
| 干粉 | 压实表面的微小凹凸、局部颗粒、离散细粉与透光前缘 | 膏体铺展、液体拉丝、浓烟、棉絮、大块碎石 |
| 纤维接触 | 真实末端、局部弯曲、接触线与极少附着颗粒；焦点服务接触证据 | 粉面变成绒毯、纤维穿透硬物、用均匀雾替代接触 |
| 特效 | 显示起点或落点，疏密与景深分层；暂时遮显后重新读清产品 | 每个物品都爆粉、无来源装饰粒子、把回落画成向外喷射 |
| 图像层次 | 主产品清楚、次要层依距离柔化；微观材质和安静背景频率有差别 | 背景铺满细节或把所有物品同等锐化 |

主体数量、尺寸、品牌、结构、材料与目标文案仍由目标 spec 控制。本文的摄影参数属于可选设计语言，不是从源图测得的真实镜头或模拟参数。此包为非人物风格，身材表单不适用。

## 从研究到画面的做法

1. **先写产品信息。** 这一幅要让人看清外壳、配方质地、接触行为，还是完整产品识别？不要为了把几张参考都放进图里而编无关故事。
2. **分清材料，再借技法。** 黑壳、压粉、纤维、镜面分别写反射、表面频率和接触方式。可以借流体广告的尺度切换；只有目标本来是膏体/液体时才借其表面张力与黏度。
3. **一个状态承担一个信息。** 可按“识别 → 触材 → 释放/展开 → 回归 → 稳定展示”组织，但只选择目标需要的状态。状态图数量不等于新增镜头数量，静帧不能验证完整动画。
4. **给元素一个归属。** 释放时写清从哪一块材料离开；回归时写清落到哪里。阵列以主次、间隔、旋转与清晰度说明关系，不把图中的多个物体误作新的SKU。
5. **保留力度，只修失败变量。** 来源候选的粗块修正说明，颗粒过粗时应修尺度与稀疏前缘，同时保留爆散方向和主体；不要顺手把整个特效变成弱雾。回归落点错误时修路径末端，不一起改产品。
6. **回看同一个标准。** 修前/修后比较同一材料区、起落点、产品结构和光线。结构通过与文件存在不能替代实际查看。

来源的返工不是无条件成功证明：修后粗块减少，部分粉流仍很密；回归方向需要结合其设计文稿理解，单张静帧本身不能证明颗粒真的向内运动。学习方法，不把每个候选像素都当作应复制的质感。

## 可选状态

- **完整单品或双状态展示**：结构优先，关键文字按目标需求准确保留，材料效果退到第二层。
- **阵列与主产品出列**：先确定数量、同款比例、近远顺序与主产品，模糊只分配给次要层。
- **接触微距**：用能看清接触线的机位；指出轻压、刚离开或已分离中的一个状态。未见的动作历程不补造。
- **细粉释放**：只用于确有粉料的目标。根部密、前缘疏，粒子的可见尺度与产品和机位相容；来源的某个数值上限不是所有产品的统一物理尺度。
- **回归材料**：产品必须有可读落点，来向/去向和遮挡要一致。若目标没有这类材料，就不用这条支线。

自然调用示例：

> 用镜造“紫序·产品微观”做这个产品的广告图。保留产品原有形状、材料与标志，选择单品、阵列或材料微距中最能说明用途的一种。质感要有宽柔反射、清楚材料分工和干净留白；只有确需展示粉料时使用细粉效果。

需要实际产品身份时仍必须附对应产品图；本次跨产品验证刻意不附客户原图，测试脱离客户资产的风格迁移。三个首轮案例为[粉彩释放](../tests/forward-specs/lilac-pastel-release.json)、[音箱阵列](../tests/forward-specs/lilac-speaker-array.json)和[刷毛接触](../tests/forward-specs/lilac-fiber-contact.json)，后续完成[粉彩细化](../tests/forward-specs/lilac-pastel-refined.json)与音箱宽画幅重发，结果与局限见[视觉记录](../tests/forward-evidence/lilac-material-reveal-review.json)。

内置图像工具只接收实际传入的正文与图片，编译 JSON 中独立的 `parameters` 不会自动抵达工具。执行时把目标画幅等必要可见要求明确转交，并分别保存编译正文、实际发送的后缀/参数和最终尺寸。本次前两条调用没有把画幅转进正文，实际返回3:2；第三条明确加入16:9后返回约16:9。后续音箱宽画幅重发与粉彩精修也实际返回约16:9。这个对照说明了输入传递差异，不构成每次尺寸精确命中的保证。

## 外部案例研究范围

本次核查采用制作方说明和页面静帧；没有在本任务重新完成它们的整段视频分析。来源项目自己的观看记录与本次核查分开。

- [Point Flottant / MAC Original Palette](https://mattiasperesini.com/work/mac-original-palette/)：制作方介绍程序化色盘结构变化；可借鉴信息拆分与重组，不借具体容量变化、包装或品牌。独立研究者读取了页面文字与静帧，主线程网页工具该页未能打开。
- [Kineza / NARS Matte Foundation](https://www.kineza.com/nars-matte-foundation-beauty-ad_3d)：制作方明确为膏体黏度开发流体模拟，描述受控铺展、表面张力与有机滴落。可借尺度与产品展示方法；干粉不能因此变成液体。
- [Builders Club / GABRIELLE CHANEL](https://builders-club.com/projects/chanel-gabrielle)：研究者读取了花、水、织物转场的制作说明和静帧；可借特效服务产品显露的职能，不迁移这些具体元素。主线程网页工具抓取超时。

公开页面未说明的镜头、粒径、求解器、预算和工时保持未知；不把制作方的品牌案例当作本风格包的技术背书。
