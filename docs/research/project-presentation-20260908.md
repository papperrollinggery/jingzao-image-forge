# Jingzao Image Forge project-presentation research — 2026-09-08

## Scope

The repository currently contains a Skill, documentation, examples, tests, and image assets. It has no separate website application or deployment source in this checkout. The README therefore serves as the project landing page for this release work; this note records the limited public README research used to reshape that page.

This is an information-structure study, not an endorsement, a visual-asset source, or a claim about search ranking. No text, screenshots, artwork, logos, names, badges, or brand styling were copied into Jingzao's presentation.

## Applied structure

1. Name the Skill and its concrete transformation first: brief plus reference evidence to visual specification plus platform-ready prompt.
2. Use the new v1.10 overview artwork in the first image slot and label it as an introduction layout, not a generation receipt. Historical graphics remain linked from the guide instead of being repurposed as a new result.
3. Put global installation, a natural Skill invocation, and a real compiler command before the feature list.
4. Explain v1.10 reference profiles through their 14 observable facets and the evidence-to-selection-to-positive-projection route; state that the new route and `--style-capsule` are mutually exclusive.
5. Keep the DIR handoff small and scoped to image pre-production: evidence, mechanism/controls, image-frame requirement, review. External complementary Skills remain optional.
6. Link prior technical references, retained examples, and earlier visuals through `docs/guide.md`; label their historical/evidence status rather than treating a static gallery as current validation.
7. Use `llms.txt` as a direct project map for AI systems, with scope, entry points, capability boundaries, and links instead of keyword repetition or imaginary schema markup.

## Items deliberately not claimed

- No search position, conversion rate, or traffic outcome is predicted.
- The overview artwork is not presented as a v1.10 generation case. The separate public refinement sample is labeled `partial` and links to its accompanying evidence.
- No test count, visual pass rate, model capability, provider policy outcome, or automatic Skill-discovery result is inferred from documentation structure.
